Read video metadata without ffmpeg.

Drop a file, pick a sample stream, or paste a URL. You get resolution, codec, framerate, HDR, rotation, bit depth and every audio and subtitle track the container declares. Only the header bytes are read, so a 40 GB file costs the same as a 4 MB one.

Worth knowing

    

      

        
Why some URLs fail here

        

          A browser can only fetch a URL whose host returns CORS headers, and remote files
          also need Range allowed on the preflight. On a server there is no such
          limit, so a URL that fails on this page still works from Node.
        

      

      

        
Local paths are server-only

        

          getVideoResolution("/path/to/video.mp4") needs a filesystem.
          In the browser you pass a File, Blob or
          ReadableStream instead, which is what the drop zone does.
        

      

      

        
Dimensions are coded, not displayed

        

          A portrait phone clip reports 1920×1080 with
          rotation: 90. Swap the axes yourself when rotation is 90 or 270.
